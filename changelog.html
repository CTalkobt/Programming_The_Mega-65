Changelog

The full history is in the Git repository.

October 19, 2026

  • Index: new index of topics, BASIC 65 keywords and registers, linked from the Contents page.
  • All pages: printing a page now leaves out the navigation bars, uses black text on white, and keeps listings and table rows from splitting across pages.
  • Chapter 2: new table of keys held at start-up, such as NO SCROLL for the core menu, a digit for MEGA65n.ROM and RUN/STOP for the monitor.
  • Chapter 3: PRINT USING lists every format character, including %D, %F, %X and zero padding, with examples and the ROMs that added them. The width in %w.pF doesn't count the decimal point, unlike in the MEGA65 Book's example.
  • Chapter 3: RND explains how each argument seeds the generator, and describes the hardware random number generator at $D7EF; TEMPO gives its range, default and beats per minute.
  • Chapter 3: in a program, SCRATCH, RENAME, COPY and the other disk housekeeping commands don't update DS and DS$, which can still hold an older message; use CLR DS before them.
  • Chapter 4: corrected the width of "%7.2F", which is eight characters, not seven.
  • Chapter 8: new list of common machine-language pitfalls.
  • Chapter 11: identifying the board and core through $D629, $D628 and $D630-$D635, and starting another core slot from a program.
  • Chapter 12: custom text screen sizes with an 88 × 30 example, horizontal character scaling with CHRXSCL, the raster rewrite buffer's time budget per line and what happens when it runs out, and a raster rewrite buffer demo in BASIC 65.
  • Chapter 13: how PLAY times notes, with a table of TEMPO values.
  • Chapter 14: D81 and D64 disk images compared, and changing disks from a program with MOUNT, MOUNT OFF, SET DISK and RDISK(1).
  • Chapter 15: USR files explained; worked examples of a notes file, a high-score table, a relative-file stock list and a program that reads the directory; a new section on disk housekeeping, with the command-channel string for each BASIC 65 disk command; listing and recovering scratched files with DIR R and SCRATCH "name",R; more drive status codes.
  • Chapter 16: Amiga mouse autodetection and the $D61B register.
  • Chapter 17: printer secondary addresses and control codes, printing from machine language, how cartridges are started, sending and receiving Ethernet frames, reading and setting the real-time clock, and the registers for DVI output and digital audio.
  • Appendix I: new memory map, gathering the 28-bit address space, bank 0 in MEGA65 mode, the CPU's view during SYS, the I/O area and the top of memory in one place.
  • Appendix J: new glossary of technical and Commodore terms, from 4510 and attic RAM to VIC, nybble, little-endian and zero page, grouped by letter, with pointers to the chapters that explain them. It also covers the PRG, SEQ, USR and REL file types.

October 18, 2026

  • Chapter 4: reorganised to follow the outline How to Become Fluent in BASIC 65; Programs, Systems, and People; Program Design; Serious and Less Serious Programming; Debugging BASIC 65 Programs; Examples in BASIC 65; and Making BASIC 65 Run Faster.
  • Chapter 4: new sections on kinds of program and their users, chaining programs with DLOAD, designing a program and a system, condition tables, documentation, soft-coding settings, error messages, menus, testing, validation with a check digit, and kinds of error.
  • Chapter 4: new worked examples, run in the Xemu emulator: a number guessing game, a key-by-key input routine, PRINT USING columns, rounding, string handling, shuffling, insertion sort and binary search, parallel arrays, a board and a stack, and dates.
  • Chapter 4: Making BASIC 65 Run Faster now has a table of timings from Xemu, and explains why constants kept in variables are faster, since a number in the program text is converted from its characters each time the line runs, and why integer variables are not.
  • Appendix H: added the articles on the MEGA65 Filehost, with a note that some were written for older ROMs and cores.
  • Chapters 6 and 9: corrected the free memory below BASIC. The ROM's graphics commands use $1800-$1FFF, so only $1600-$17FF is safe in every program; the examples in Chapters 3, 6 and 11 now use $1600.
  • Chapter 12: the default palette follows the C64's colour order but not its colours; added a program that loads C64-like colours.
  • Chapter 15: the @ save-and-replace bug affects every Commodore drive, not just the 1541 and 1571, and the MEGA65's own DOS fixed it in ROM 920303.
  • Chapter 3: DS and DS$ keep their values until the next disk operation, CLR DS clears them, and status codes below 20 are not errors.
  • Chapter 6: the screen-saving example now has a version that works in any text mode, using SCRNPTR and RWINDOW.
  • Chapter 2: added the escape sequences ESC N and ESC R (line pushing), ESC ↑ and ESC ← (save and restore the cursor), ESC Z, ESC G and ESC H, and ESC [ and ESC ], with an example that prints in the bottom-right corner.
  • Chapter 7: new section, Development Tools, covering the cc45 suite, other assemblers and C compilers, Xemu, mega65-tools and m65dbg.
  • Chapter 7: Development Tools adds vbcc, C64 Studio and CBM prg Studio, and a section on assembling on the MEGA65 itself with EasyAsm.
  • Chapter 16: reading a 1351 mouse without BASIC's driver, with a tested routine; SET FAST MOUSE (ROM 920422); a warning about Sega Mega Drive controllers.
  • Chapter 11: new example, restoring the display with IOINIT and CINT, and which display settings IOINIT keeps.
  • Chapter 11: a note on RESET_RUN's undocumented mode 3, a Hypervisor reset followed by RUN, and how the ROM implements the modes.
  • Chapter 14: system files must be updated with each core; the Freezer forgets the directory of a mounted image; new section on keeping disk images in one piece on the card.
  • Chapter 3: SAVEIFF saves 8-bitplane screens from ROM 920417.

October 15, 2026

  • Appendices: added Appendix H, Sources and Further Reading, listing the MEGA65 User Guide repository, the mega65-core source code, Dan Sanderson's MEGA65 pages and the ROM change log.
  • Chapter 1: the Sources note now names these sources and points to Appendix H.
  • Chapter 3: reorganised the opening into a BASIC Syntax section, in the order Numbers and Literals, Variables, Operators, Functions, Expressions and Statements. New text covers string literals, variable names, arrays, functions, expressions, how values are stored in integer and byte variables, and program lines and direct mode.
  • Chapter 3: grouped the keyword entries under a new BASIC Keywords section. Each category in Categories at a Glance now links to its entries, and a new Symbols and Special Names table shows where each symbol and reserved name is described.
  • Chapter 3: added examples so that every keyword appears in at least one example, including WHILE, EXIT, FGOTO, COS, TAN, BVERIFY, DIRECTORY, CATALOG, SAVE, VERIFY, PRINT#, LINE INPUT#, GET#, FWRITE#, ERASE, UNLOCK, HEADER, FOREGROUND, RPALETTE, GRAPHIC, RPEN, DMODE, CUT, RSPRITE, RSPRSYS and FAST. The new examples were run in the Xemu emulator.
  • Chapter 3: replaced the example of a long variable name, since SPEED, the name the MEGA65 Book uses, is a keyword in BASIC 65.
  • Chapter 3: added an Error Handling section at the end of BASIC Syntax. It covers how errors are reported, catching them with TRAP and RESUME, disk and device status, and finding the cause, and it lists every BASIC 65 error number with its cause.

October 14, 2026

  • Chapter 3: explained what RENUMBER's C (crunch) option does and which ROM added it.
  • Chapter 3: made clear that the ↑, ← and / shortcuts take a file name; ↑ loads and runs a file rather than running the program in memory, and on its own gives ?MISSING FILE NAME ERROR.

  • Chapter 11: described VERSIONQ under "Identifying the version", including the ROM release that added it (920417), and the version string at $20016, which is discouraged.
